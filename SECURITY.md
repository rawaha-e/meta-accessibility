# Security

## Reporting a vulnerability

For public issues (for example, one with a released CVE number), open an issue
at https://github.com/rawaha-e/meta-accessibility/issues.

For anything not yet public, email the maintainer listed in the README
instead of opening an issue.

Please include the recipe, its version and the branch you are using.

Problems in the software itself (espeak-ng, speech-dispatcher, brltty,
liblouis, ...) should also be reported to that upstream project. This layer
picks up fixes by updating recipes or backporting patches.

## Supported branches

Security fixes go to `main` and `wrynose`.
